한 번의 업무가 지나가는 길

모든 직원은 1초마다 자기 수신함과 배정된 업무를 들여다봅니다. 아래는 그 루프가 실제로 찍는 활동 로그 문구입니다.

  1. nextJob()

    일을 집는다

    메신저에 답할 메시지가 쌓였거나, todo 상태의 업무가 배정되면 그 순서대로 깨어납니다. 아무도 없으면 대기합니다.

  2. chat()

    생각한다

    직원마다 다른 모델·다른 키로 도구 호출을 시도합니다. 팀 구성과 직급, 회사 목표가 시스템 지침으로 들어갑니다.

  3. runTool()

    도구를 쓴다

    웹 검색, 페이지 읽기, 클릭·입력, 마우스 드래그, MCP 도구까지. 허용되지 않은 도구는 호출 자체가 거부됩니다.

  4. completeTask()

    보고한다

    결과를 지시자에게 보냅니다. 오너가 시킨 일이면 1:1 대화로, 상사가 시킨 일이면 상사 수신함으로 올라갑니다.

읽고 실행하세요

실제 PC를 조작합니다

컴퓨터 유즈를 켜면 AI가 이 컴퓨터의 마우스와 키보드를 실제로 움직입니다. 가상 머신이나 버려둘 계정에서 돌리는 것을 권합니다. 첫 실행이라면 MAX_STEPS=8처럼 단계 수를 짧게 잡아 두세요.

  • 기본은 안전쪽. PC 조작 마스터 스위치와 브라우저 헤드리스 모드는 꺼짐/켜짐 상태로 시작합니다.
  • 비상 정지. 상단의 일시정지는 진행 중인 사고와 도구 호출을 즉시 끊고, 마우스·키보드 점유를 해제합니다.
  • 되돌릴 수 없는 행동 금지. 파일 삭제·결제·송금·계정 설정 변경·메일 발송은 오너의 명시적 허락 없이 하지 못하도록 지침에 들어 있습니다.
  • 키는 브라우저로 내려오지 않습니다. 화면과 WebSocket에는 앞 네 글자만 마스킹된 형태(••••1234)로 전달됩니다.

실행해 보기

Node 18+면 됩니다. npm install이 Chromium까지 함께 설치합니다.

terminal
git clone https://github.com/purplemacaron/virtual-company.git
cd virtual-company
npm install
npm start
  Virtual Company → http://localhost:3000

환경 변수

  • PORT3000
  • DATA_FILE./data.json
  • MAX_STEPS업무당 최대 사고 단계

첫 실행 순서

  1. 설정 탭에서 쓸 모델의 API 키를 넣습니다.
  2. 오너로서 회사 목표를 한 줄 적습니다.
  3. 업무 시작을 누르고 오피스 탭에서 지켜봅니다.
